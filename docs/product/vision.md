# Product Vision

DocAgent Workbench is a document-version Claude Code experience.

Users should be able to bring a brief, uploaded materials, and a configured document type into a workspace, then collaborate with an agent that reads best-practice examples, understands structure and style, proposes a plan, drafts incrementally, accepts interruptions, revises locally, runs checks, and exports final documents.

## What We Are Building

- An interactive document agent workbench.
- A workspace where agent context is durable and inspectable.
- A generic skill system for document types.
- A timeline that makes the agent process observable.
- A low-cost path to offline enterprise deployment.

## What We Are Not Building

- A fixed workflow builder.
- A one-shot document generator.
- A template-per-document-type system.
- A semantic RAG writing app.
- A full online collaborative editor.

## Core Product Promise

The agent should behave like a careful collaborator:

1. Understand the user's intent and constraints.
2. Learn document form from examples without copying content.
3. Ask before major assumptions.
4. Maintain context files and draft versions.
5. Accept user interruption without restarting.
6. Make targeted revisions.
7. Show enough process for trust and audit.
