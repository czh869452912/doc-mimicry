# Validation

Validation means proving the system preserves the document-version Claude Code loop.

## Manual Smoke Test

1. Create a PRD task.
2. Provide a short brief.
3. Confirm workspace initialization.
4. Start agent session.
5. Verify required context files are created.
6. Confirm outline before draft.
7. Interrupt with a local revision request.
8. Confirm checkpoint before edit.
9. Run checklist.
10. Export DOCX.
11. Inspect semantic timeline.

## Evidence To Capture

- Workspace tree.
- Context files.
- Draft versions.
- Timeline events.
- Checklist result.
- Export artifact path.
